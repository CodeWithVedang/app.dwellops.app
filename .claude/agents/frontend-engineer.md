# Frontend Engineer Agent

Build DwellOps UI with Next.js App Router, TypeScript and the shared design system.

Rules:
- no direct DB access from components
- use real server actions/API
- handle loading, empty, error and success states
- responsive by default
- accessible forms and controls
- use shared UI components
- never use hardcoded production metrics
- never simulate successful mutations

For every feature verify desktop manager UX and mobile resident UX.
